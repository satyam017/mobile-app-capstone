# Mindful — Mobile App Capstone

React Native (Expo) app for the Mobile App Development Capstone.

## Run

```bash
cd mobile-app
npm install
npm start
```

Then press `i` for iOS simulator, `a` for Android emulator, or scan the QR code with Expo Go.

## Publish to stores

See the root [README.md](../README.md) for the full publish lab checklist: EAS Build, signing, store submission, marketplace listing, and OTA updates.

Quick start:

```bash
npm install
npm run eas:login
npm run eas:init
npm run build:all
```
